# Загрузка удалённых изображений

Spatie использует `Services\RemoteImages\SpatieImageDownloader` через штатный
`media-library.media_downloader`. Конфигурация и исходники vendor не изменяются.
Настройки приложения находятся в `config/remote-images.php`.

Для товаров разрешены **точные** хосты `api.bcraftfest.ru` и `untappd.com`.
Если Untappd возвращает ссылку на другой CDN, она будет отклонена. Добавляйте
домен в `untappd_hosts` только после проверки источника. Не добавляйте домены
автоматически по данным импорта. Для VK список остаётся в
`services.vk.image_hosts`, с разрешением поддоменов по границе точки.

Требуются PHP cURL с `CURLOPT_RESOLVE`, Fileinfo и GD с JPEG/PNG/WebP.
При отсутствии транспорта или декодера загрузка завершается отказом.
TLS проверяется всегда, в том числе при `MEDIA_DOWNLOADER_SSL=false`:
этот существующий ключ пакета сохранён, но новый адаптер не отключает TLS.
Исходящий proxy из переменных окружения не используется.

Перед каждой загрузкой проверяются все DNS-ответы A/AAAA. Соединение закреплено
за проверенным публичным IP, имя хоста сохраняется для TLS. Редиректы запрещены.
Соединение ограничено 5 секундами, передача — 15 секундами; время системного
DNS-разрешения определяется настройками резолвера ОС, отдельно от таймера cURL.
Поток ограничен 10 MiB либо меньшим лимитом Media Library. После скачивания
проверяются MIME, размеры (8192 на сторону, 20 млн пикселей) и декодирование.

При вызове Spatie из нового места используйте
`app(RemoteImageDownloader::class)->withCleanup(fn () => ...)`, охватывая
`addMediaFromUrl` и `toMediaCollection`: это удалит временный файл также при
отказе Media Library. При прямом вызове `download` вызовите `release` после
использования результата. Существующие пути импорта и обновления товара уже
используют эту очистку.

VK скачивает изображение для проверки и удаляет копию, сохраняя исходный URL.
Кеш результатов сбрасывается при каждом запуске `vk:sync-posts`. Проверка
не гарантирует неизменность URL при последующей загрузке сторонним сервисом.

После развёртывания обновите кеш конфигурации и перезапустите долгоживущие
queue workers. Миграций БД и изменений настроек хостинга нет. Ошибки картинки
не прерывают импорт товара; ошибки VK сохраняются в `rejected_images`.
Предыдущее изображение товара при отказе загрузки остаётся на месте.

Проверки DNS и HTTP в тестах подменены. Никаких запросов к внутренним сервисам
или реальным источникам изображений для тестирования делать не нужно.
