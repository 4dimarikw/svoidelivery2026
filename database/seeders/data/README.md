# Снимок текущих данных сайта

`current-site.php` — снимок локальной базы от 12 сентября 2026 года:
settings (24), site_sections (2), site_menus (1), site_menu_items (1),
content_blocks (2), связанные content_block_items (8), telegraph_bots (1).
Исходные записи, ID, JSON, порядок и связи сохранены. Медиафайлы в снимок
не входят: у блоков на момент экспорта их нет.

Запуск после миграций:

```shell
php artisan db:seed --class=CurrentSiteDataSeeder
```

Сидер также подключён к `DatabaseSeeder` перед сидерами настроек.
Существующие настройки определяются по паре group/name и не изменяются
(включая значения, уже созданные settings-миграциями). Импортируются только
отсутствующие настройки. Снимок не сбрасывает существующие значения к своим.
CMS импортируется только при пустых пяти таблицах контента целиком;
частично заполненный CMS пропускается, чтобы не смешивать идентификаторы.
Боты импортируются только при пустой telegraph_bots. Повторный запуск
сохраняет редакторские изменения. Ошибка импорта откатывает транзакцию.
Очистка кеша выполняется после фиксации транзакции: ошибка на этом этапе
не откатывает сохранённые данные. После исправления можно повторить запуск.

Токены ботов находятся в `current-site.local.php`, исключённом из Git.
Для переноса на другой компьютер скопируйте этот файл безопасным способом
либо скопируйте `current-site.local.example.php` в `current-site.local.php`
и заполните токены по ID ботов из снимка. Без токенов импорт в пустую таблицу
ботов завершается явной ошибкой, без частичного заполнения остальных таблиц.
Сидер не вызывает Telegram API.

`site-content.php` и `SiteContentSeeder` остаются отдельным установочным
набором типового контента; этот снимок их не заменяет.
